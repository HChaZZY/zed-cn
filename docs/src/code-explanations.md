# AI 代码讲解

在设置的 AI 分类中启用“代码讲解”，选择讲解渠道和模型。也可以通过右下角“AI 讲解”菜单开关、选择模型、重新讲解、清除缓存和打开设置。开启意味着允许将当前阅读的代码和函数签名发送给明确选择的模型服务；不会回退到其他提供商。

讲解显示在相应代码上方，有 `AI` 标识，不写入文件，不进入 Git diff 或撤销历史，普通复制仍只复制代码。解释可能不准确，不能代替检查代码本身。

## 加载和限制

只在聚焦的普通单文件代码编辑器按可见区域加载，停留 500 毫秒后请求。语法支持依赖文件语言的 Tree-sitter 解析器。无解析器、压缩文件、敏感文件和不可信项目不自动讲解。默认没有文件行数限制。

单个函数或顶层代码单元超过 `max_function_lines`（默认 500）时，在函数上方询问是否继续。确认仅对当前内容有效，编辑后需要重新确认。大型函数按命名语法节点拆分，单个不可拆分且超出预算的节点不发送。原有注释始终保留；默认跳过已有相邻注释覆盖的讲解位置。

代码修改、配置变化、焦点离开会取消不再需要的请求。当前实现编辑后移除该编辑器的讲解，再从未改变代码单元的缓存恢复。跨文件调用只依据已提供的代码解释，不自动上传仓库。

## 缓存

数据库保存在应用本机数据目录的 `code-explanations/<项目标识>.sqlite`，不在项目 `.zed` 内。远程连接信息和项目根路径参与隔离；内容、语言、函数签名、模型配置、语言和详细程度参与缓存身份，键使用 SHA-256。

每项目默认讲解文本预算为 50 MiB，全局数据库预算为 500 MiB，自动淘汰较旧内容。数据库有少量结构开销；后台 SQLite 操作失败不影响编辑。关闭持久化不删除已有数据库，可使用状态栏清除缓存。缓存不保存完整源文件，但讲解本身可能包含敏感信息。

## 配置

```json
"code_explanations": {
  "enabled": false,
  "provider": null,
  "model": null,
  "target_language": "中文",
  "max_function_lines": 500,
  "detailed": false,
  "prefer_existing_comments": true,
  "cache_persist": true,
  "cache_max_bytes": 52428800
}
```

复杂语法、注释覆盖识别和 AI 返回行号都可能存在局限。Diff、多文件搜索结果、非聚焦编辑器和没有语法解析器的文件不在自动讲解范围内。
